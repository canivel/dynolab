# Where did the budget come from?

An exploratory Qwen3.8 drafting study: four tasks, each with an underspecified request, explicit placeholders, and supplied facts. Two underspecified answers contained clear unsupported details, one contained an ambiguous illustrative example, and one requested more information. All eight controls avoided unsupported named, numeric or dated specifics under the recorded rubric.

This follow-up was motivated by a previous fundraising response. It is not a blind confirmation, a general hallucination rate, or evidence of deception. Review was unblinded and model-assisted. Read [every response and review](run/REPORT.md), [the rubric](run/review.json), and [protocol](PROTOCOL.md). Run `python examples/unsupported-details/run.py` in the project MLX environment to repeat generation. Check model revision and environment in `run/manifest.json`; new responses require a new review, not reuse of old labels.
