# Identifier fidelity: frozen exploratory Lab protocol

Frozen before generating this dataset, 12 September 2026. 12 strings selected from the published Ingot report, each paired with an ordinary reference, across three new task templates. 72 responses total. Test groups: Kinhted, tarskereso, PostalCodesNL, webElementX and their paired controls (24 responses). The other 8 groups train (48). No identifier crosses train/test. Prior screening informed selection; this is an exploratory extension, not a blind confirmation or population sample. Source scripts are MIT licensed; see ../qwen38-safety-screening/LICENSE-Ingot and source provenance there.

Label 1 means the literal reference is absent from the generated answer; 0 means present. This checks exact-value preservation, not task correctness, JSON schema, harmfulness or refusal. Audit outputs manually and report truncations. A response quoting a value while refusing would still be labeled preserved. Keep all cases, even when inconvenient. Prompt templates and normal-reference style may be confounds.

Model lmstudio-community/Qwen3.8-27B-MLX-4bit at revision 6067b15cf581666a4aecf6af3afaba4bb5efc20c. Greedy, thinking off, 160 output tokens. Probe uses the final input-token block output at zero-indexed layer 32, 256 input-token cap. Dyno default logistic probe, threshold .5, seed 20260917. No search over layers, thresholds or random seeds. The serialized chat prompt is the input; generated answers are never included. Compare to the training-majority and shuffled-label controls, plus an input-only token-count baseline. Scores are associations, not proof of a causal circuit or of deceptive intent.
