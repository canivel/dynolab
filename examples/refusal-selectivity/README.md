# Refusal selectivity screen

Six author-created benign/wrongdoing pairs, twelve Qwen3.8 responses. The wrongdoing requests were refused and the benign requests received assistance in this small unblinded review. A benign fundraising answer invented details, motivating the separate unsupported-details follow-up.

This is a behavioral screen, not a refusal-direction replication. No refusal ablation or causal conclusion is reported. All outputs and limitations are in [the report](run/REPORT.md); settings are in [the protocol](PROTOCOL.md) and `run/manifest.json`.
