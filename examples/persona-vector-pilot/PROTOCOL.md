# Published persona-prompt contrast on Qwen3.8

Exploratory feasibility study, separate from the negative factual pilot. Registered before this run: first four questions from the pinned upstream extraction file, each under the first positive and negative instruction pair; first two evaluation questions as neutral baselines. No prompt or layer search. Layer 32, thinking disabled, greedy generation, 160 output tokens, combined capture limit 512 tokens. All responses are kept, including truncations. Upstream file hashes and commit are in `upstream/manifest.json`; preserve its Apache 2.0 license.

This is a modern-model adaptation of the [published persona-vector implementation](https://github.com/safety-research/persona_vectors), not a faithful benchmark replication. It changes model, quantization, runtime, sample size and adds a common two-sentence constraint. It omits the published assistant-name prefix. The upstream paper uses scored/coherent pairs, not condition names as behavior labels. Do not equate subjective agreement with factual error.

Capture performs a fresh forward pass over the serialized prompt plus generated response, following the upstream replay approach. Tokenization must retain an exact prompt prefix or the case fails explicitly. Save last-prompt, mean-prompt and mean-response representations separately. Each response receives equal weight when aggregating across examples, regardless of its length. Do not average the whole conversation or include prompt tokens in the response mean. EOS is not appended. These are raw block outputs: block 32 corresponds to the post-block hidden-state position, not Transformers hidden-state index 32. Architecture/final-normalization conventions need checking for any cross-runtime comparison.

Before vector extraction, create a condition-blinded review packet and assess observable excessive agreement, one-sidedness, flattery, and coherence. Record reviewer identity, rubric and whether evaluation is model-assisted. With only four pairs, report examples and descriptive contrasts, not generalization accuracy. Do not call instructions observed labels. Extraction and evaluation questions remain separate; no selection or tuning on evaluation outputs.

If a coherent trait contrast exists, compute equal-example mean positive-minus-negative response representations on the selected extraction pairs. Record all exclusions. A subsequent fixed-strength steering test needs zero-strength and random-direction controls, plus helpfulness/coherence evaluation. A representational difference alone is not causal evidence or a safety improvement.
